# Lumina

An intractive bulb or ambient room light simulator build from scratch with html css and js 
---
tech stack

 html5:-  Incline SVG is used to create a hanging bulb with a chain to control it on and of option

cs :- s used variables like --dim, --speed and many more to make it smoother and responsive 

javascript :- handles the pointer drag physicsswitch click sound dynamic color theme and state management of dom 

web Audio api :-  is used for generating click sound with pure code no .mp3 files is requied 

---
## key feature
 intractive pull chain switch is used to control the lamp 

 pendulam bulb pulling bulb the chain or clicking makes it swing 

dynamic theme switch between multiple theme as you want and enable it to change automatically 

 mobile responsive bottom docked control panel that adapts cleanly to both phone and desktop 

---
how it runs locally 
since this project uses pure html css and js so no installation is required just 
**clone the repository**
```bash
git clone https://github.com/evvacarter/Lumina.git
```
simply double click on index.html to open it any web browser or open vs code and run it using the live server
